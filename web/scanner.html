配置识别服务

在项目目录复制 config.example.json 为 config.local.json，填入你自己的 API 密钥和可用的视觉模型。

{
  "api_key": "你的 API 密钥",
  "model": "gpt-4.1",
  "base_url": "https://api.openai.com/v1"
}

保存后刷新页面即可，无需重启。密钥只由本地服务器读取，不会传给浏览器。自动识别会按 API 使用量计费。

当前版本要求服务支持 Responses 图片接口。没有密钥时，仍可使用示例、手动摆棋、校对和导出。
